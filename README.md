# 小禾学伴 · 教育智能体交接仓库

交接整理：2026-11-02。仓库包括手机端、教研 Web/业务原型、原始需求、市场调研、可安装安卓试用包、历史发布和验收材料，以及去除邀请令牌哈希的本地试验数据快照。

**先看 [同事接手指南](交接文档/同事接手指南.md) 和 [本次检查结果](交接文档/本次检查结果.md)。** 本次手机 229 项、Web 237 项测试通过，构建/双端代码导出通过；Expo Doctor 有 11 项补丁版本更新建议，19/20 检查通过，已保留原锁版并记录后续处理。 本项目仍处于本地试点阶段：Android 有独立试用 APK；iOS 尚未原生编译/运行验收；生成式 AI、语音、正式账号/云同步和商店发布尚未完成。

## 同事第一次打开

1. **立即试用安卓**：下载 [ARM64 试用 APK](构建备份-20261028/xiaohe-local-trial-arm64.apk)，复制到兼容安卓手机安装。也可在启动自己的 ARM64 模拟器后，于 `xiaohe-mobile` 执行 `node scripts/install-trial-apk.mjs`。这是开发签名包，完整功能不依赖 Metro 或业务账号。
2. **看需求与待办**：[V2 总体需求](小禾学伴V2.pdf)、[手机版](小禾学伴-手机端.pdf)、[管理端介绍](小禾学伴-管理端介绍.pptx)、[实施计划](APP-实施计划.md)。
3. **开始开发**：[手机工程](xiaohe-mobile/README.md)、[教研 Web 工程](xiaohe-app/README.md)，使用各自锁文件安装依赖。首次 Web 初始化和历史数据恢复是两种不同路径，详见接手指南。
4. **了解历史**：[上次接手说明](给下一位AI的接手提示词.md)、[目录与数据审计](交接文档/教育项目审计.md)、[历史验收文档](xiaohe-mobile/docs/ocr-trial-validation.md)。旧说明中的绝对路径、原电脑工具链和模拟器不可直接照用。

## 交付边界

- 已实现的是本机学习、题库提示/讲解、作答/证据、照片 OCR 人工核对等试用闭环；不是已上线完整教育平台。教学星级参数和样题尚未经教学有效性验证。
- 本地私有 Sites 旧站点与原所有者绑定，GitHub 不会自动转移站点、Cloudflare 数据、账号、域名、签名或付费资源的管理权。
- 当前目录没有原手机 `outputs/toolchain` / AVD / `outputs/qa` 的设备快照。手机学习记录在原 App 或模拟器私有存储，不在 Git 源码中；本仓库没有虚称恢复这部分。
- 排除 node_modules、生成原生工程、依赖缓存、登录 cookie/session 和有效邀请凭证；保留锁文件、源码和可重建步骤。
